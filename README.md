# Network Delay VPN для iOS

iOS приложение для симуляции задержки сети через локальный VPN.

## Возможности

- 🔒 Локальный VPN без внешних серверов
- ⏱️ Настройка задержки от 0 до 2000 мс
- 📱 Простой и понятный интерфейс
- 🔄 Изменение задержки в реальном времени

## Требования

- iOS 15.0+
- Xcode 15.0+
- Swift 5.9+

## Установка

### Локальная сборка

1. Клонируйте репозиторий:
```bash
git clone <your-repo-url>
cd NetworkDelayVPN
```

2. Откройте проект в Xcode:
```bash
open NetworkDelayVPN.xcodeproj
```

3. Настройте подписание:
   - Выберите проект в навигаторе
   - Выберите таргет "NetworkDelayVPN"
   - Во вкладке "Signing & Capabilities" выберите вашу команду разработчика
   - Повторите для таргета "PacketTunnel"

4. Запустите на устройстве или симуляторе

### GitHub Actions

Проект настроен для автоматической сборки через GitHub Actions. При каждом пуше в ветки `main` или `develop` запускается сборка.

## Использование

1. Запустите приложение
2. Выберите желаемую задержку с помощью слайдера или быстрых кнопок
3. Нажмите "Подключить VPN"
4. Разрешите создание VPN конфигурации в системных настройках
5. Задержка применяется ко всему сетевому трафику устройства

## Архитектура

- **ContentView**: Главный интерфейс приложения
- **VPNManager**: Управление VPN подключением
- **PacketTunnelProvider**: Network Extension для обработки пакетов

## Важные замечания

⚠️ **Для работы на реальном устройстве требуется:**
- Платный аккаунт Apple Developer
- Правильная настройка App ID с Network Extension capability
- Provisioning Profile с поддержкой Network Extension
