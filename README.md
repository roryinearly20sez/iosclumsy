# Network Delay VPN для iOS

iOS приложение для симуляции задержки сети через **настоящий локальный VPN**.

## ⚠️ ВАЖНО: Требования для работы VPN

Для работы VPN функционала на реальном устройстве **ОБЯЗАТЕЛЬНО** требуется:

1. **Платный Apple Developer аккаунт** ($99/год)
2. **App ID с Network Extension capability**
3. **Provisioning Profile с поддержкой Network Extension**

### Настройка для реального устройства:

1. Зайдите на https://developer.apple.com/account
2. Создайте App ID с включенным "Network Extensions"
3. Создайте Provisioning Profile для этого App ID
4. В Xcode:
   - Выберите ваш Team в Signing & Capabilities
   - Убедитесь что Bundle ID совпадает с App ID
   - Повторите для PacketTunnel extension

## Возможности

- 🔒 **Настоящий локальный VPN** через NEPacketTunnelProvider
- ⏱️ Настройка задержки от 0 до 2000 мс
- 📱 Простой интерфейс
- 🔄 Изменение задержки в реальном времени
- 🌐 Работает со всем сетевым трафиком устройства

## Как это работает

Приложение создает локальный VPN туннель который:
1. Перехватывает все сетевые пакеты
2. Добавляет настраиваемую задержку
3. Отправляет пакеты дальше

Это позволяет тестировать приложения в условиях медленной сети.

## Установка

### Симулятор (ограниченная функциональность)
```bash
git clone https://github.com/roryinearly20sez/iosclumsy
cd iosclumsy
open NetworkDelayVPN.xcodeproj
```

### Реальное устройство
1. Настройте Apple Developer аккаунт
2. Создайте App ID с Network Extensions
3. Обновите Bundle ID в проекте
4. Выберите ваш Team в Signing
5. Соберите и установите на устройство

## Использование

1. Запустите приложение
2. Выберите задержку (0-2000 мс)
3. Нажмите "Подключить VPN"
4. Разрешите VPN в системных настройках
5. Весь трафик теперь идет с задержкой!

## Архитектура

- **NetworkDelayVPN** - основное приложение с UI
- **PacketTunnel** - Network Extension для обработки пакетов
- **VPNManager** - управление VPN подключением
- **PacketTunnelProvider** - обработчик сетевых пакетов с задержкой
